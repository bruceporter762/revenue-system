# Runbook update — adding reel-script-writer and distribution-lead

Merge this into your existing `revenue-agent-runbook.md`. Don't replace the whole file — just insert these two steps into the sequence.

## Updated sequence

1. **market-signal-researcher** (existing) — finds and scores real demand
2. **offer-architect** (existing) — designs the offer based on validated demand
3. **content-angle-strategist** (existing) — picks the content angle
4. **reel-script-writer** (new) — turns the angle into a finished, postable script with hook variants, shot list, and caption
5. **distribution-lead** (new) — turns finished scripts into an actual posting calendar and flags bottlenecks
6. **conversion-system-builder** (existing) — builds the landing page / email flow the content is driving traffic toward

Note: step 6 doesn't have to wait for steps 4-5 to finish — the conversion assets (landing page, email capture, abandoned cart flow) can be built in parallel with script/distribution work, since both depend on step 2's offer, not on each other.

## Why this order

The original 4-agent system stopped at "here's your content angle" — a strategy document, not a finished asset. Two things were missing: turning that angle into something filmable (reel-script-writer), and actually getting it posted with a real cadence instead of sitting in a doc (distribution-lead). Research → offer → angle → script → distribution is the actual path from an idea to a live post; skipping either of the last two steps means the first four steps produce strategy with no output.

## When to run this for By Celebration specifically

Per the current `business-brief.md`, the store isn't fully conversion-ready yet (blog posts unpublished, abandoned cart flow not built, domain unconfirmed). Recommended order for this business right now:

1. Close the 4 "immediate priority" items in the brief first — publish blog posts, build abandoned cart flow, confirm domain, get IG/Pinterest accounts live
2. Then run reel-script-writer + distribution-lead to start a consistent posting cadence
3. Run conversion-system-builder in parallel once traffic starts landing somewhere real

Posting reels that point at a store with no abandoned cart recovery and no live blog content is spending content effort ahead of conversion infrastructure that isn't there yet.
